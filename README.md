# vBulletin 6 Translation Repository

This repository serves as a centralized resource for collecting, updating, and sharing language pack files for the vBulletin 6 forum management system. The primary goal is to help forum administrators run vBulletin 6 in multiple languages.

## Repository Structure
Translation files are exported as XML files from the vBulletin AdminCP and stored in separate directories based on language codes (e.g., `fa-IR` for Persian, `en-US` for English).

## How to Use
1. Download the XML file for your desired language from this repository.
2. In your vBulletin AdminCP, navigate to **Languages & Phrases > Download / Upload Languages**.
3. In the Upload section, upload the XML file to install or update the language.
